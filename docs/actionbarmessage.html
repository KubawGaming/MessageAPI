ActionBarMessage

Display messages in the action bar (above the hotbar).

Configuration (YAML)

health-warning:
  actionbar: "<red>⚠ Low Health: {HEALTH}/20"
  commands:
  - "effect give {PLAYER} regeneration 5 1"
  messageDelay: 40
  sound:
    paths:
    - "block.note_block.bass"
    - "entity.experience_orb.pickup"
    delay: 10
    volume: 0.5
    pitch: 0.8

Developer Usage

Basic Usage

ActionBarMessage message = new ActionBarMessage("<yellow>⚠ Warning!");
message.sendTo(player);

With Placeholders

ActionBarMessage message = new ActionBarMessage("<green>Health: {HEALTH} | Hunger: {HUNGER}");
message.replace("{HEALTH}", player.getHealth())
       .replace("{HUNGER}", player.getFoodLevel())
       .sendTo(player);
