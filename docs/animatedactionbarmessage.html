AnimatedActionBarMessage

Displays a sequence of action bar messages (frames) with individual timing per frame. Perfect for loading bars, countdowns, etc.

Configuration (YAML)

With defaultTime

animatedActionBarMessage:
  defaultTime: 20
  animatedActionBar:
  - message: "<red>▪▪▪▪▪"
  - message: "<yellow>▪<red>▪▪▪▪"
  - message: "<yellow>▪▪<red>▪▪▪"
  - message: "<yellow>▪▪▪<red>▪▪"
  - message: "<yellow>▪▪▪▪<red>▪"
  - message: "<green>▪▪▪▪▪"
  commands:
  - "give {PLAYER} diamond 1"
  sound:
    paths:
    - "minecraft:entity.experience_orb.pickup"
    delay: 10
    volume: 1.0
    pitch: 1.0

Individual frame timing (overrides defaultTime)

animatedActionBarMessage:
  defaultTime: 30
  animatedActionBar:
  - message: "<yellow>Loading."
  - message: "<yellow>Loading.."
  - message: "<yellow>Loading..."
  - message: "<green>Complete!"
    time: 60
defaultTime: Sets the default display time (in ticks) for all frames that don't specify their own time field. 20 ticks = 1 second.

How Frames Work

Each frame is an object with two properties:

  • message - The action bar text displayed during this frame (supports MiniMessage formatting).
  • time - (Optional) How long the frame stays visible (in ticks). Uses defaultTime if omitted.

Frames play sequentially from first to last. After the final frame, the animation stops automatically.

Automatic Keep-Alive: Minecraft's action bar normally disappears after ~40 ticks. AnimatedActionBarMessage automatically refreshes long-lasting frames to prevent flickering or disappearing during animation. This is handled internally - no configuration needed.

Developer Usage

Basic Animation with Frames

List<ActionBarAnimationData> frames = List.of(
    new ActionBarAnimationData("<red>▪▪▪▪▪", null),
    new ActionBarAnimationData("<yellow>▪<red>▪▪▪▪", null),
    new ActionBarAnimationData("<yellow>▪▪<red>▪▪▪", null),
    new ActionBarAnimationData("<green>▪▪▪▪▪", 60)
);

AnimatedActionBarMessage animation = new AnimatedActionBarMessage(frames);
animation.setDefaultTime(20); // All frames without explicit time use 20 ticks
animation.sendTo(player);

Countdown Timer

List<ActionBarAnimationData> frames = new ArrayList<>();

for(int i = 10; i >= 0; i--) {
    frames.add(new ActionBarAnimationData(
        "<yellow>Teleporting in <red>" + i + "<yellow> seconds",
        20
    ));
}

AnimatedActionBarMessage countdown = new AnimatedActionBarMessage(frames);
countdown.setCommands(List.of("spawn {PLAYER}"));
countdown.sendTo(player);

With Placeholders

List<ActionBarAnimationData> frames = List.of(
    new ActionBarAnimationData("<aqua>Hello, {NAME}!", 40),
    new ActionBarAnimationData("<green>Welcome back!", 40)
);

AnimatedActionBarMessage animation = new AnimatedActionBarMessage(frames);
animation.replace("{NAME}", player.getName())
          .setSoundPaths(List.of("minecraft:entity.player.levelup"))
          .sendTo(player);

Preventing Multiple Animations

The system automatically stops any existing animation for a player before starting a new one. No manual cleanup required.
