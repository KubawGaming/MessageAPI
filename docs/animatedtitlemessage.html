AnimatedTitleMessage

Displays a sequence of titles as an animation. Each frame can have its own timing and display settings.

Configuration (YAML)

Basic Animation with defaultTime

animatedTitleMessage:
  defaultTime: 40
  defaultFadeIn: 10
  defaultStay: 60
  defaultFadeOut: 10
  animatedTitle:
  - title: "<red><bold>ROUND 1"
    subtitle: "<gray>Get ready!"
  - title: "<:yellow><bold>FIGHT!"
    subtitle: "<red>GO GO GO!"
  commands:
  - "give {PLAYER} diamond 1"
  sound:
    paths:
    - "minecraft:entity.player.levelup"
    delay: 10
    volume: 1.0
    pitch: 1.0

Individual Frame Settings (Override Defaults)

animatedTitleMessage:
  defaultTime: 30
  defaultFadeIn: 5
  defaultStay: 40
  defaultFadeOut: 5
  animatedTitle:
  - title: "<gold>LEVEL 1"
    subtitle: "<gray>Easy"
    time: 60
    stay: 80
  - title: "<:yellow>LEVEL 2"
    subtitle: "<gray>Medium"
  - title: "<red><bold>LEVEL 3"
    subtitle: "<dark_red>HARD"
    fadeIn: 20
    stay: 100
    fadeOut: 20
Default Values: The following defaults can be set at the root level and apply to all frames unless overridden:
  • defaultTime - Duration of each frame in ticks (default: 1 tick)
  • defaultFadeIn - Title fade-in time in milliseconds (default: 0)
  • defaultStay - Title display time in milliseconds (default: 60)
  • defaultFadeOut - Title fade-out time in milliseconds (default: 0)

How Frames Work

Each frame is an object with the following properties:

PropertyTypeDescription
titleStringMain title text (optional, supports MiniMessage)
subtitleStringSubtitle text (optional, supports MiniMessage)
fadeInIntegerFade-in time in milliseconds (overrides defaultFadeIn)
stayIntegerDisplay time in milliseconds (overrides defaultStay)
fadeOutIntegerFade-out time in milliseconds (overrides defaultFadeOut)
timeIntegerDuration of this frame in ticks (overrides defaultTime)

Frames play sequentially from first to last. After the final frame, the animation stops automatically.

Note: Unlike animated action bars, titles don't require keep-alive logic. Each title appears with its configured fadeIn/stay/fadeOut timing, then waits for the next frame.

Developer Usage

Basic Animation with Frames

List<TitleAnimationData> frames = List.of(
    new TitleAnimationData("<gold>Round 1", "<gray>Get ready", 10, 60, 10, 40),
    new TitleAnimationData("<yellow>Round 2", "<gray>Faster!", null, null, null, 40),
    new TitleAnimationData("<red>Final Round", "<dark_red>BOSS!", 20, 80, 20, 60)
);

AnimatedTitleMessage animation = new AnimatedTitleMessage(frames);
animation.setDefaultFadeIn(5)
         .setDefaultStay(40)
         .setDefaultFadeOut(5)
         .setDefaultTime(30)
         .sendTo(player);

Storytelling / Cutscene Titles

List<TitleAnimationData> story = List.of(
    new TitleAnimationData("", "<gray>A long time ago...", 20, 60, 20, 60),
    new TitleAnimationData("<gold>The Hero Rises", "<yellow>Legendary Sword obtained", 30, 80, 30, 80),
    new TitleAnimationData("<green>Quest Complete", "<gray>+5000 XP", 10, 100, 20, 50)
);

new AnimatedTitleMessage(story)
    .setSoundPaths(List.of("minecraft:ui.toast.challenge_complete"))
    .broadcast();

Countdown with Subtitles

List<TitleAnimationData> frames = new ArrayList<>();

for(int i = 5; i > 0; i--) {
    frames.add(new TitleAnimationData(
        "<red>" + i,
        "<gray>Get ready to teleport",
        10, 20, 10, 20
    ));
}
frames.add(new TitleAnimationData(
    "<green>GO!",
    "<yellow>Teleporting now",
    10, 40, 10, 30
));

AnimatedTitleMessage countdown = new AnimatedTitleMessage(frames);
countdown.setCommands(List.of("spawn {PLAYER}"))
         .sendTo(player);

With Placeholders

List<TitleAnimationData> frames = List.of(
    new TitleAnimationData("<aqua>Welcome, {NAME}!", "<gray>Level {LEVEL}", 10, 60, 10, 40),
    new TitleAnimationData("<green>Enjoy your stay!", null, 10, 40, 10, 30)
);

AnimatedTitleMessage animation = new AnimatedTitleMessage(frames);
animation.replace("{NAME}", player.getName())
         .replace("{LEVEL}", player.getLevel())
         .broadcast();

Preventing Multiple Animations

The system automatically stops any existing title animation for a player before starting a new one. No manual cleanup required.
