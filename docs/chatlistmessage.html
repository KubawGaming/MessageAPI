ChatListMessage

Send multiple chat messages sequentially. Perfect for multi-line announcements.

Configuration (YAML)

info-message:
  messageType: CHAT_LIST
  message:
  - "<green>========== Server Info =========="
  - "<yellow>Players online: {ONLINE}"
  - "<yellow>Server uptime: {UPTIME}"
  - "<green>================================="
  messageDelay: 20
  commands:
  - "give {PLAYER} diamond 1"
  sound:
    paths:
    - "minecraft:block.note_block.pling"
    volume: 0.8
    pitch: 1.0

Developer Usage

Basic Usage

ChatListMessage message = new ChatListMessage(List.of(
    "<green>========== Welcome ===========",
    "<yellow>Enjoy your stay!",
    "<green>=============================="
));
message.sendTo(player);

With Placeholders

ChatListMessage message = new ChatListMessage(List.of(
    "<aqua>Player Stats:",
    "<gray>Name: {NAME}",
    "<gray>Level: {LEVEL}",
    "<gray>Balance: {BALANCE}"
));
message.replace("{NAME}", player.getName())
       .replace("{LEVEL}", 15)
       .replace("{BALANCE}", 1000)
       .sendTo(player);

Console Messages

Special Feature: ChatListMessage has built-in console support for logging or debugging.

Send to Console (with colors)

ChatListMessage message = new ChatListMessage(List.of(
    "<green>Server started!",
    "<yellow>Plugin version: {VERSION}"
));
message.replace("{VERSION}", plugin.getDescription().getVersion())
    .sendToConsole();

Send to Console (without colors)

message.sendToConsole(false); // Plain text only
