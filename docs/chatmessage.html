ChatMessage

The most basic message type for sending standard chat messages to players. Supports MiniMessage formatting, placeholders, sounds, and commands.

Configuration (YAML)

Basic Message

welcome-message:
  message: "<green>Welcome to the server, <player>!"

With Sound

level-up-message:
  message: "<gold><bold>LEVEL UP!"
  sound:
    paths:
      - "entity.player.levelup"
    volume: 1.0
    pitch: 1.2

With Commands

daily-reward:
  message: "<yellow>Daily reward claimed!"
  commands:
    - "give {PLAYER} diamond 5"
    - "eco give {PLAYER} 1000"

With Delay

delayed-message:
  message: "<red>Server restarting in 5 seconds!"
  messageDelay: 100  # 5 seconds

Developer Usage

Basic Usage

ChatMessage message = new ChatMessage("<green>Hello, world!");
message.sendTo(player);

With Placeholders

ChatMessage message = new ChatMessage("<aqua>Welcome, <player>!");
message.replace("<player>", player.getName())
       .sendTo(player);

With Sound

ChatMessage message = new ChatMessage("<gold>Achievement unlocked!");
message.setSoundPaths(List.of("ui.toast.challenge_complete"))
       .setSoundVolume(1.0f)
       .setSoundPitch(1.0f)
       .sendTo(player);

With Commands

ChatMessage message = new ChatMessage("<yellow>Reward received!");
message.setCommands(List.of(
    "give {PLAYER} diamond 1",
    "effect give {PLAYER} speed 30 1"
));
message.sendTo(player);

With Delay

ChatMessage message = new ChatMessage("<red>Delayed message!");
message.sendTo(player, 40); // 2 seconds delay

// Or using setter
message.setMessageDelay(40)
       .sendTo(player);

Broadcasting

ChatMessage message = new ChatMessage("<red><bold>Server Announcement!");
message.broadcast();

// Broadcast to specific world
message.sendTo(world);

// Broadcast with permission
message.broadcast("myplugin.announcements");

Conditional Sending (Predicates)

ChatMessage message = new ChatMessage("<gold>VIP Announcement!");

// Send to all online players matching a condition
message.broadcast(player -> player.getLevel() > 10);

// Send to single player if condition matches
message.sendTo(player, p -> p.getHealth() < 5.0);

Console Messages

Special Feature: ChatMessage has built-in console support for logging or debugging.

Send to Console (with colors)

ChatMessage message = new ChatMessage("<green>Server started successfully!");
message.sendToConsole();

Send to Console (without colors)

ChatMessage message = new ChatMessage("<green>Server started successfully!");
message.sendToConsole(false); // Plain text only
