Custom Message Types

Create your own message types by extending the base classes provided by MessageAPI.

Class Hierarchy

Message (abstract)
├── LocalizedMessage (abstract)
│   └── SoundableMessage (abstract)
│       ├── ChatMessage
│       ├── ChatListMessage
│       ├── ActionBarMessage
│       ├── AnimatedActionBarMessage
│       ├── TitleMessage
│       ├── AnimatedTitleMessage
│       ├── MultiMessage
│       └── EmptyMessage
└── (your custom messages)

Base Classes Overview

Message

The root abstract class. Provides:

  • messageDelay - Delay before sending (in ticks)
  • commands - List of console commands to execute (supports {PLAYER} placeholder)
  • sendTo*() - Built-in delivery methods (broadcast, permission filters, radius, predicates)
  • replace() - Placeholder replacement system
  • clone() - Immutable operations support
  • adventure - BukkitAudiences instance for custom delivery
  • Utility methods: sendMessage(), sendActionBar(), sendTitle(), applyCommands()

LocalizedMessage

Extends Message. Adds support for location-based messages.

SoundableMessage

Extends LocalizedMessage. Adds sound effects support:

  • soundSettings - Paths, delay, volume, pitch
  • applySound() - Plays sound to recipient
  • inLocation() - Sets sound playback location

Creating a Custom Message - BossBar Example

Complete Implementation

@JsonTypeName("BOSSBAR")
@Getter
@Setter
@Accessors(chain = true)
public class BossBarMessage extends SoundableMessage {

    @JsonProperty("message") private String message;
    @JsonProperty("progress") private float progress;
    @JsonProperty("color") private BossBar.Color color;
    @JsonProperty("style") private BossBar.Style style;

    @JsonCreator
    public BossBarMessage(
            @JsonProperty("message") String message,
            @JsonProperty("progress") float progress,
            @NotNull @JsonProperty("color") BossBar.Color color,
            @NotNull @JsonProperty("style") BossBar.Style style
    ) {
        this.message = message;
        this.progress = progress;
        this.color = color;
        this.style = style;
    }

    @Override
    protected BossBarMessage sendToInternal(@NotNull Player player) {
        applySound(player);
        applyCommands(player);
        
        adventure.player(player).showBossBar(
            BossBar.bossBar(Utils.hexComponent(message), progress, color, style)
        );
        return this;
    }

    @Override
    public BossBarMessage replace(@NotNull String toReplace, @NotNull String replaced) {
        BossBarMessage cloned = this.clone();
        cloned.message = cloned.message.replace(toReplace, replaced);
        return cloned;
    }

    @Override
    public BossBarMessage clone() {
        return (BossBarMessage) super.clone();
    }
}

Step-by-Step Breakdown

1. Annotations

@JsonTypeName("BOSSBAR")  // Unique type name for YAML/JSON
@Getter @Setter            // Lombok - generates getters/setters
@Accessors(chain = true)   // Enables method chaining (setX().setY())

2. Extend the Right Base Class

public class BossBarMessage extends SoundableMessage

Use SoundableMessage if you want sound support. Use Message directly if not.

3. Define Fields with @JsonProperty

@JsonProperty("message") private String message;
@JsonProperty("progress") private float progress;
@JsonProperty("color") private BossBar.Color color;
@JsonProperty("style") private BossBar.Style style;

4. Add @JsonCreator Constructor

@JsonCreator
public BossBarMessage(
        @JsonProperty("message") String message,
        @JsonProperty("progress") float progress,
        @NotNull @JsonProperty("color") BossBar.Color color,
        @NotNull @JsonProperty("style") BossBar.Style style
) {
    this.message = message;
    this.progress = progress;
    this.color = color;
    this.style = style;
}

5. Override sendToInternal()

@Override
protected BossBarMessage sendToInternal(@NotNull Player player) {
    applySound(player);      // Plays configured sound (if any)
    applyCommands(player);   // Executes configured commands
    
    // Your custom delivery logic - access adventure field directly
    adventure.player(player).showBossBar(
        BossBar.bossBar(Utils.hexComponent(message), progress, color, style)
    );
    return this;
}
Note: The adventure field is protected static in the Message class, so you can access it directly in your custom message type.

6. Override replace()

@Override
public BossBarMessage replace(@NotNull String toReplace, @NotNull String replaced) {
    BossBarMessage cloned = this.clone();
    cloned.message = cloned.message.replace(toReplace, replaced);
    return cloned;
}

7. Override clone()

@Override
public BossBarMessage clone() {
    return (BossBarMessage) super.clone();
}

Registering Your Custom Type

Important: Register your custom message type after calling Message.init(). 
// During plugin startup
Message.init(this);
Message.registerMessageType(BossBarMessage.class);

YAML Configuration Example

boss-bar:
  messageType: BOSSBAR
  message: "<red>Boss Health: {HEALTH}/100"
  progress: 0.75
  color: "RED"
  style: "SEGMENTED_10"
  commands:
  - "say Boss took damage!"
  sound:
    paths:
    - "minecraft:entity.ender_dragon.growl"
    volume: 1.0
    pitch: 0.8

Developer Usage

BossBarMessage bossBar = new BossBarMessage(
    "<red>Dragon Fight!",
    0.5f,
    BossBar.Color.RED,
    BossBar.Style.SEGMENTED_10
);
bossBar.setCommands(List.of("effect give {PLAYER} strength 10 1"))
       .setSoundPaths(List.of("minecraft:entity.ender_dragon.growl"))
       .sendTo(player);

Available Utility Methods

// From Message class (can access directly via adventure field)
protected void sendMessage(CommandSender sender, Component message)
protected void sendActionBar(Player player, Component message)
protected void sendTitle(Player player, Component title, Component subtitle, int fadeIn, int stay, int fadeOut)
protected void applyCommands(Player player)

// From SoundableMessage class
protected void applySound(Player player)

// Static utility
Utils.hexComponent("<red>Hello") // Converts MiniMessage to Component (supports hex colors `&#XXXXXX` for older versions)
Note: If your message doesn't require sound or location, extend Message directly. Only extend SoundableMessage if you want sound effects.
