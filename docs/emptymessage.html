EmptyMessage

A message that displays nothing to the player. Useful for executing commands or playing sounds without any visual output.

Configuration (YAML)

Minimal (Does Absolutely Nothing)

do-nothing:
  messageType: EMPTY

With Commands and Sound

silent-reward:
  messageType: EMPTY
  messageDelay: 20
  commands:
  - "give {PLAYER} diamond 1"
  - "effect give {PLAYER} speed 30 1"
  sound:
    paths:
    - "minecraft:entity.experience_orb.pickup"
    - "minecraft:entity.player.levelup"
    volume: 1.0
    pitch: 1.2

Developer Usage

Basic Usage

EmptyMessage message = new EmptyMessage();
message.sendTo(player);

With Commands

EmptyMessage message = new EmptyMessage();
message.setCommands(List.of("give {PLAYER} diamond 1", "eco give {PLAYER} 100"));
message.sendTo(player);

With Sound

EmptyMessage message = new EmptyMessage();
message.setSoundPaths(List.of("minecraft:entity.firework_rocket.blast"))
       .setSoundVolume(1.5f)
       .setSoundPitch(0.8f)
       .sendTo(player);

Example Use Cases

  • Silent command execution (e.g., giving items without notification)
  • Playing sounds without visual feedback
  • Conditional actions based on message delays
  • Placeholder for messages that should be disabled
