MultiMessage

Groups multiple messages into one. Each sub-message is sent sequentially and maintains its own configuration.

Configuration (YAML)

welcome-sequence:
  messageType: MULTI
  messages:
  # Message 1 (ChatMessage)
  - messageType: CHAT
    message: "<green>Welcome to the server!"
    commands:
    - "say {PLAYER} joined!"
    - "give {PLAYER} diamond 1"
    sound:
      paths:
      - "minecraft:entity.player.levelup"
      delay: 10
      volume: 1.0
      pitch: 1.2
  # Message 2 (TitleMessage)
  - messageType: TITLE
    title: "<gold><bold>WELCOME"
    subtitle: "<gray>Enjoy your stay!"
    fadeIn: 10
    stay: 60
    fadeOut: 20
    commands:
    - "effect give {PLAYER} speed 30 1"
    sound:
      paths:
      - "minecraft:ui.toast.challenge_complete"
      delay: 5
      volume: 0.8
      pitch: 1.0
  # Message 3 (ActionBarMessage)
  - messageType: ACTIONBAR
    message: "<yellow>Type /help to get started"
    messageDelay: 20

Developer Usage

Combine Multiple Message Types

MultiMessage multi = new MultiMessage(List.of(
    new ChatMessage("<green>You leveled up!"),
    new TitleMessage("<gold>LEVEL UP!", null, 10, 40, 10),
    new ActionBarMessage("<yellow>+10 HP & +5 Strength")
));
multi.sendTo(player);

Each Message Has Its Own Configuration

ChatMessage chat = new ChatMessage("<green>Boss defeated!");
chat.setCommands(List.of("give {PLAYER} netherite_sword 1"));
chat.setSoundPaths(List.of("minecraft:entity.player.levelup"));

TitleMessage title = new TitleMessage("<gold>VICTORY!", "<gray>+500 XP", 10, 50, 10);
title.setSoundPaths(List.of("minecraft:ui.toast.challenge_complete"));

MultiMessage multi = new MultiMessage(List.of(chat, title));
multi.sendTo(player);

With Placeholders (applies to all sub-messages)

MultiMessage multi = new MultiMessage(List.of(
    new ChatMessage("<aqua>Welcome, {NAME}!"),
    new TitleMessage("<green>{NAME}", "<gray>Level: {LEVEL}", 10, 50, 10),
    new ActionBarMessage("<yellow>Balance: {BALANCE}")
));
multi.replace("{NAME}", player.getName())
    .replace("{LEVEL}", player.getLevel())
    .replace("{BALANCE}", 1000)
    .sendTo(player);
