TitleMessage

Display large titles and subtitles in the center of the screen.

Configuration (YAML)

Full Example

welcome-title:
  messageType: TITLE
  title: "<gold><bold>WELCOME"
  subtitle: "<gray>to our server, {PLAYER}!"
  fadeIn: 10
  stay: 60
  fadeOut: 20
  commands:
  - "give {PLAYER} diamond 1"
  messageDelay: 40
  sound:
    paths:
    - "minecraft:ui.toast.challenge_complete"
    - "minecraft:entity.player.levelup"
    delay: 10
    volume: 1.0
    pitch: 1.2

Minimal Example (Uses Default Values)

simple-title:
  messageType: TITLE
  title: "<red><bold>WARNING!"
Important: All timing values are in milliseconds, not ticks! (1000ms = 1 second)

Property Reference

Property Type Default Description
title String - Main title text (optional, supports MiniMessage)
subtitle String - Subtitle text (optional, supports MiniMessage)
fadeIn Integer 0 Fade-in time in milliseconds
stay Integer 1000 Display time in milliseconds
fadeOut Integer 0 Fade-out time in milliseconds
Note: Both title and subtitle are optional. You can omit either field, and it will be treated as empty. All fade/stay fields are also optional - they will use the default values shown above if not specified.

Developer Usage

Basic Usage (Using Defaults)

// All timing parameters use defaults (fadeIn=0, stay=1000, fadeOut=0)
TitleMessage message = new TitleMessage("<gold><bold>WELCOME", "<gray>Enjoy your stay!", null, null, null);
message.sendTo(player);

Custom Timing

TitleMessage message = new TitleMessage(
    "<aqua>Player Stats",
    "<gray>Level: {LEVEL} | Kills: {KILLS}",
    10, 60, 20
);
message.replace("{LEVEL}", player.getLevel())
       .replace("{KILLS}", 150)
       .sendTo(player);

Title Only (No Subtitle)

TitleMessage message = new TitleMessage("<red><bold>WARNING!", null, 10, 40, 10);
message.sendTo(player);

Using Setters with Null Values (Uses Defaults)

TitleMessage message = new TitleMessage("<green>Welcome!", null, null, null, null);
// Or create via setters
message.setTitle("<green>Welcome!");
message.sendTo(player);
