WebhookMessage

Allows sending messages and embeds directly to a Discord channel via a webhook URL.

Configuration (YAML)

This is an example of all settings for the WEBHOOK message type.

webhook-alert:
  messageType: WEBHOOK
  webhook: "https://discord.com/api/webhooks/your-webhook-id/token"
  message: "Hello from the server!"
  username: "ServerBot"
  avatarUrl: "https://example.com/avatar.png"
  embeds:
    - title: "Server Notification"
      description: "This is an embed message sent from Minecraft."
      url: "https://example.com"
      color: 16711680
      timestamp: "2026-07-12T14:00:00Z"
      thumbnailUrl: "https://example.com/thumb.png"
      imageUrl: "https://example.com/image.png"
      author:
        name: "Author Name"
        iconUrl: "https://example.com/author.png"
      footer:
        text: "MessageAPI"
        iconUrl: "https://example.com/icon.png"
      fields:
        - name: "Field 1"
          value: "Value 1"
          inline: false
        - name: "Field 2"
          value: "Value 2"
          inline: true
        - name: "Field 3"
          value: "Value 3"
          inline: true
        - name: "Field 0"
          value: "You can use fields without inline property, but it will be set to false by default."

Developer Usage

When creating a WebhookMessage, the webhook URL is mandatory.

Basic Usage

WebhookMessage message = new WebhookMessage(
    "webhookUrl",
    "message",
    "username",
    "avatarUrl",
    List.of(
        Embed.builder()
            .title("title")
            .color(0xFF0000)
            .description("description")
            .fields(List.of(
                Field.builder().name("name1").value("value1").inline(true).build(),
                Field.builder().name("name2").value("value2").inline(true).build()
            ))
            .build()
    )
);
message.sendTo(sender);

Using Embeds

Embed embed = Embed.builder()
    .title("Title")
    .description("Description")
    .color(0xFF0000)
    .build();

WebhookMessage message = new WebhookMessage("webhookUrl", "MC Webhook", null, null, List.of(embed));
message.sendTo(sender);

// For WebhookMessage it's allowed (but not recommended) to send message to null sender
message.sendTo(null);

// Or, more logically using class WebhookMessage built-in method:
message.sendWebhookMessage();

Error Logging

By default, WebhookMessage logs errors to the console for every webhook (this option is enabled by default). If you wish to disable this logging, you can do it by setting logWebhookErrors to false:

WebhookMessage.setLogWebhookErrors(false);
